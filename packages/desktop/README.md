# @ide/desktop

Dev-оболочка Electron для разработки самой IDE. Не сборка и не `.app`: просто нативное окно вокруг dev-стека.

## Запуск

```
pnpm desktop                 # стартовый экран: создать, открыть или склонировать проект
pnpm desktop -- /path/to/project
pnpm desktop -- .            # разработка самой IDE в IDE: core остаётся под --watch
```

Другой проект можно открыть и из UI (диалог открытия проекта); «Close project» в нём возвращает на стартовый экран.

`main.mjs` за один запуск:

1. генерирует случайный токен;
2. поднимает vite dev server UI и core (`node --watch ...`, токен в `IDE_CORE_TOKEN`) на свободных портах, которые выдаёт ОС (порты не фиксированы, с запущенными `dev:core`/`dev:ui` не конфликтуют);
3. ждёт, пока оба порта слушают, и открывает окно на `http://localhost:<порт UI>/#token=<токен>`.

Закрытие окна (или Ctrl+C в терминале) завершает оба процесса вместе с потомками.

## Как работает рестарт

- Правка UI: vite HMR, окно не перезагружается.
- Правка core: `node --watch` перезапускает core, пока открыт проект, заданный в командной строке (`pnpm desktop -- .`). Токен лежит в окружении родителя (электрон-процесса), поэтому после рестарта тот же. Порт core выбран один раз за запуск и не меняется при рестартах, vite проксирует `/ws` на него (`IDE_CORE_PORT`). UI сам переподключается с backoff (`net/socket.ts`), URL и окно не меняются.

## Ограничения

- Рестарт core останавливает агента текущего чата: процесс `claude` дочерний у core. Оболочка ставит `IDE_AUTO_RESUME=1`: после рестарта core сам возобновляет сессию (`--resume`) сообщением «продолжай с места остановки». Отключить: убрать эту переменную в `main.mjs`.
- Проект, открытый со стартового экрана или переключённый из UI, обслуживает новый процесс core без `--watch`: правки core не подхватываются до перезапуска `pnpm desktop`. Правка в этом состоянии заново запустит исходный `node --watch`-процесс, он упрётся в занятый порт и завершится с `EADDRINUSE`. Для разработки самой IDE запускайте `pnpm desktop -- .` и не переключайте проект из UI.
- Токен и порт нужны только окну; открывать ссылку из лога core в обычном браузере можно, но только пока оболочка запущена.
